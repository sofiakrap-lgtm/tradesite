# Logot

| Tiedosto | Käyttö |
|---|---|
| `tradesite-logo.svg` | Header ja footer. Upotetaan sivulle inline-SVG:nä, väri tulee teemasta (currentColor) |
| `tradesite-logo-stacked.svg` | Pystyversio |
| `tradesite-mark.svg` | Pelkkä merkki |
| `tradesite-wordmark.svg` | Pelkkä teksti |
| `png/` | PNG-versiot (tumma, vaalea, valkoinen) muuhun käyttöön |

Faviconit: `assets/favicon/`. Jakokuva ja some-avatarit: `assets/og/`. Alkuperäiset koodinpätkät: `docs/logo-snippets/`.
Logon vaihto: korvaa `tradesite-logo.svg` ja aja `npm run build`.
