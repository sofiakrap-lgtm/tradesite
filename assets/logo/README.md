# Logot

Tähän kansioon tulevat Tradesiten lopulliset logot. Build ottaa ne käyttöön automaattisesti.

| Tiedosto | Käyttö | Muoto |
|---|---|---|
| `logo.svg` | Header ja footer (korvaa väliaikaisen TRADESITE-tekstilogon) | SVG, tumma (#24221E) läpinäkyvällä taustalla, korkeus skaalautuu 28 px:iin |
| `logo-light.svg` | Tummat taustat (varalla) | SVG, vaalea (#EBE5DC) |
| `favicon.svg` | Selaimen välilehti | SVG, neliö 64 x 64. Nyt väliaikainen T-merkki |
| `apple-touch-icon.png` | iPhonen kotivalikko | PNG 180 x 180 |

Kun `logo.svg` on lisätty: `npm run build`. Muuta ei tarvitse tehdä.
